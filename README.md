My online portfolio, powered by [`create-svelte`](https://github.com/sveltejs/kit/tree/main/packages/create-svelte).

## Developing

Clone repo and run `npm install` (or `pnpm install` or `yarn`). Start the dev server:

```bash
npm run dev

# or start the server and open the app in a new browser tab
npm run dev -- --open
```

Updating components: the .svelte files in src/lib/components 
Updating site itself: routes/+page.svelte 

## Deploying

Push to github - netlify will pick it up.
